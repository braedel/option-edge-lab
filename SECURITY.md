# Security Policy

This is a personal quantitative-research portfolio project. It contains no live
trading code, no credentials, and no raw market data (see `.gitignore` and
`CLAUDE.md` — secrets and data are never committed).

## Reporting a vulnerability

If you find a security issue in this repository (e.g. a leaked credential or a
vulnerable dependency), please report it privately:

- Preferred: GitHub **private vulnerability reporting** on this repository
  ("Report a vulnerability" under the Security tab), or
- Email: bretraedel@gmail.com

Please do not open a public issue for security reports. You should receive a
response within a few days.

## Scope

- Research/backtesting code only; nothing here places live orders.
- Dependency vulnerabilities are monitored via Dependabot.
