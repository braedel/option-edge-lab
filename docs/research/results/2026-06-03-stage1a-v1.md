## Question
Do the differentiated signals add **incremental** out-of-fold skill over a crowded realized-vol baseline
for the forward states short-vol selling needs (quiet tape `fwd_rv`, no down-move `fwd_dd`)? v1 signal
set `D = {gex, dix}` (SqueezeMetrics daily, lagged). Baseline `B` = trailing realized vol (5/10/21d) +
5d return + day-of-week. Nested models, purged walk-forward (embargo=h, OOS sealed), Diebold-Mariano HAC
t-test on the loss differential, BH-corrected across the grid.

## Interpretation
- **Vol persistence already contains what GEX knows.** Trailing realized vol is a strong forward-vol
  predictor; GEX is redundant with it for this purpose and only adds estimation variance (overfits).
  GEX is not "useless" in isolation — it is non-incremental over the baseline you'd condition on anyway.
- Consistent with the **deflated prior**: SqueezeMetrics GEX/DIX are retail-sold (semi-crowded); calm vs
  storm is already priced into realized-vol persistence.

## What this does — and does NOT — kill
- **Kills:** conditioning daily/weekly vol-selling on **off-the-shelf GEX/DIX** as a forward-vol/down-move
  forecaster.
- **Does NOT test:** (a) the owner's **own** futures order-flow / absorption (v2) — a genuinely
  differentiated, *non*-retail signal; (b) a self-computed 0DTE gamma proxy (v3); (c) the **VRP-richness /
  IV-RV-gap timing** channel (needs the options surface = a data pull, Stage-1b). All untested — but the
  prior on them is now **lower**: the obvious differentiated vol signal failed, and the horizon-coupling
  headwind (short-horizon signals vs multi-day forward vol dominated by persistence) is now empirical.

## Recommendation (deflated)
Spend v2 effort only with genuine conviction the futures flow carries **multi-day** forward-vol info that
realized vol lacks. Otherwise this avenue looks like the crowded/priced trade the meta-prior warned about,
and stopping or pivoting (e.g., to an intraday horizon where flow lives, accepting 0DTE-efficiency risk)
is the honest call. No data spend incurred; OOS intact.
